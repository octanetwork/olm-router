🚀 Quick Setup & Configuration

Run Claude Code pointing directly to your OLM Router instance:

export ANTHROPIC_BASE_URL="https://api-olm.octx.space" export ANTHROPIC_API_KEY="olm_live_your_key_here" claude

Add to ~/Library/Application Support/Claude/claude_desktop_config.json:

{ "inferenceGateways": { "default": { "baseUrl": "https://api-olm.octx.space", "apiKey": "olm_live_your_key_here" } } }

When experiencing mobile operator throttling or TSPU blocks, route via the whitelisted reserve endpoint:

export ANTHROPIC_BASE_URL="https://wapi-olm.octx.space" export ANTHROPIC_API_KEY="olm_live_your_key_here" export ANTHROPIC_CUSTOM_HEADERS="x-olm-lte-bypass: octa-lte-emergency" claude

Configure standard OpenAI compatible clients (Cursor, Aider, LibreChat):

OpenAI Base URL: https://api-olm.octx.space/v1 API Key: olm_live_your_key_here Models: claude-3-8-flash, claude-qn-coder, claude-seek-r1
